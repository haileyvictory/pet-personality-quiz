# privacy.mdREAD ME

Your quiz stays with you

Your optional name and answers stay in page memory. No accounts, uploads, analytics, cookies, local or session storage, or AI service calls. Reloading clears the quiz.

To keep the homepage showcase fresh, only the last sample Blobby's identifier is remembered in the current page's history entry. No name or answer is saved there.

GitHub Pages receives normal hosting requests and network metadata, including IP addresses. Read GitHub's privacy statement for details. Following an external link takes you to that site's privacy practices.

A little credit where it's due

Blobby and the hat sprites are Microsoft Corporation artwork from the MIT-licensed VS Code project. The 24 personality illustrations combine those sprites with custom colors and original pixel-art props. They are playful quiz styles, not actual VS Code achievement unlocks.

The human scenarios and personality descriptions are original quiz writing. Results use a fixed scoring system, not AI or a scientific personality model. You can revisit your answers without randomly changing the result.

Bring Blobby into your editor

Download VS Code, open GitHub Copilot Chat, and try /vscode-pet. Newer versions may use /blobby. Blobby's context menu includes Achievements and their accessory rewards. See the official Blobby guide for the current experimental feature.

This is an independent, unofficial project. It is not endorsed by Microsoft or GitHub, and it is not a real personality assessment.
